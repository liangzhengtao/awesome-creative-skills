# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

This project contains AI prompt templates and design guidelines. While there are no traditional software vulnerabilities to report, we take the following concerns seriously:

### Content Safety

If you find any skill file that:
- Contains harmful, offensive, or inappropriate content
- Includes prompts that could generate harmful imagery
- Violates intellectual property or copyright
- Contains misleading or dangerous instructions

Please report it immediately.

### How to Report

1. **Email**: Open a private security advisory on GitHub
2. **GitHub**: Use the [Security Advisories](https://github.com/liangzhengtao/awesome-creative-skills/security/advisories/new) feature
3. **Issue**: For non-sensitive concerns, open a regular [issue](https://github.com/liangzhengtao/awesome-creative-skills/issues)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 1 week
- **Resolution**: Depends on severity, typically within 2 weeks

## Scope

This security policy covers:
- All files in the `skills/` directory
- Prompt templates and their potential misuse
- Content that may violate platform policies
- Copyright and intellectual property concerns

## Best Practices for Contributors

When creating or reviewing skill files:

1. **No personal information** — Don't include real names, addresses, or private data in examples
2. **Respect copyright** — Reference artistic styles, don't copy protected works
3. **Platform compliance** — Ensure prompts comply with AI platform content policies
4. **Age-appropriate content** — All content should be appropriate for general audiences
5. **Cultural sensitivity** — Be respectful of cultural elements and traditions

## 安全政策

### 报告漏洞

此项目包含AI提示词模板和设计指南。如发现以下问题，请立即报告：

- 包含有害、攻击性或不当内容
- 包含可能生成有害图像的提示词
- 违反知识产权或版权
- 包含误导性或危险的指示

### 如何报告

1. 在GitHub上使用安全公告功能
2. 对于非敏感问题，请提交普通Issue

### 响应时间

- **确认**：48小时内
- **初步评估**：1周内
- **解决**：视严重程度，通常2周内
