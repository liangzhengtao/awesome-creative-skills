# Content Creator Pack

> Category: 社交媒体 (Social Media) | Style: Multi-Platform Content Design | Last updated: 2026

## When to Use

Create engaging, platform-optimized social media content across all major platforms. Perfect for:

- Instagram posts, stories, reels covers, and carousels
- YouTube thumbnails, channel art, and community posts
- Twitter/X headers, post images, and thread graphics
- LinkedIn banners, post images, and article covers
- TikTok covers and profile optimization
- Pinterest pins and board covers
- Facebook covers, posts, and event images
- Newsletter headers and email graphics

## Design Philosophy

Social media design is **attention engineering** — you have 0.5-3 seconds to stop the scroll:

- **Thumb-stopping power** — High contrast, bold color, unexpected compositions
- **Platform native** — Each platform has its own visual culture and norms
- **Scannable hierarchy** — Title → hook → supporting visual → CTA
- **Consistency builds brand** — Recurring elements create recognition in the feed
- **Mobile-first** — Design for the smallest screen; scale up for larger
- **Accessible by default** — Text must be readable, colors must contrast

## Decision Priority

1. **Platform requirements** — Dimensions, safe zones, character limits
2. **Content type** — Post, story, carousel, thumbnail, banner
3. **Visual style** — Matching brand guidelines and audience expectations
4. **Text overlay** — Concise, readable, well-placed
5. **Engagement optimization** — Elements that drive interaction

## Instructions for AI Assistant

### Step 1: Identify Platform and Format
Confirm the exact platform, content type, and dimensions.

### Step 2: Determine Content Strategy
- What is the goal? (awareness, engagement, click-through, conversion)
- What type of content? (educational, entertaining, inspirational, promotional)
- What is the hook? (first line / visual that stops the scroll)

### Step 3: Build the Design Prompt
```
Base: "[PLATFORM] [FORMAT] design, [CONTENT TYPE], style: [VISUAL STYLE],
[COLOR SCHEME], typography: [FONT TREATMENT], layout: [COMPOSITION],
text: '[HEADLINE]', '[SUBTEXT/CTA]', [BRAND ELEMENTS], [SPECIAL EFFECTS],
dimensions: [WIDTH x HEIGHT], mobile-optimized"
```

### Step 4: Generate Variations
Create 2-3 variations for A/B testing.

## Prompt Templates

### Instagram Post (Square 1080×1080)

**Quote Card:**
```
Instagram quote card design, square format 1080x1080px, clean and impactful
layout. Quote: "[QUOTE TEXT]" — [ATTRIBUTION]. Style: [MINIMAL/BOLD/ELEGANT/
PLAYFUL], [BACKGROUND: solid color / gradient / texture / photo with overlay],
[DECORATIVE ELEMENTS: quotation marks / line dividers / icons], typography:
[PRIMARY FONT] for quote in [SIZE/WEIGHT], [SECONDARY FONT] for attribution,
color palette: [PRIMARY] background with [TEXT COLOR] text, [ACCENT] for
decorative elements. Must be readable at thumbnail size. Brand handle
@[HANDLE] small in corner.
```

**Carousel Design (Multi-slide):**
```
Instagram carousel design, 5-10 slides, 1080x1080px each, cohesive visual
system. Slide 1: Hook — "[ATTENTION-GRABBING HEADLINE]" with [VISUAL HOOK].
Slides 2-8: Content — each slide covers [TOPIC POINT], with [NUMBER] and
[BRIEF TEXT], consistent [LAYOUT STYLE: list / comparison / step-by-step].
Slide 9: Summary/CTA — "[CALL TO ACTION]" with [SAVE/SHARE PROMPT]. Style:
[VISUAL DIRECTION], consistent [COLOR] and [TYPOGRAPHY] across all slides,
[NAVIGATION ELEMENT: slide numbers / progress bar], swipe indicator on
first slide.
```

**Story Design (1080×1920):**
```
Instagram story design, 1080x1920px, vertical format. Content: [TYPE:
announcement / poll / quiz / countdown / swipe-up / behind-the-scenes].
Top: [HEADLINE TEXT] in bold. Center: [MAIN VISUAL / PHOTO / GRAPHIC].
```

### YouTube Thumbnail (1280×720)

```
YouTube thumbnail design, 1280x720px, optimized for click-through rate.
Subject: [DESCRIPTION OF MAIN IMAGE/PERSON], [EXPRESSION: shocked / excited /
pointing / thinking], high contrast background of [COLOR/GRADIENT/IMAGE],
large bold text: "[THUMBNAIL TEXT — MAX 4 WORDS]" in [IMPACT/ANTON/BEBAS
NEUE], [COLOR TREATMENT: color pop / duotone / outline / shadow], [VISUAL
ELEMENTS: arrows / circles / before-after / numbered list], [EMOTION HOOK:
curiosity gap / transformation / result reveal]. Design must be instantly
readable at mobile thumbnail size (120×68px). Avoid: cluttered text,
small fonts, subtle differences.
```

**Thumbnail Styles:**
| Style | Description | Best For |
|-------|-------------|----------|
| Face + Reaction | Large expressive face, 2-3 word text | Vlogs, reactions, storytelling |
| Before/After | Split screen transformation | Tutorials, reviews, fitness |
| Numbered List | Bold number + preview items | "Top 10", listicles, tips |
| Text-Only | Massive bold typography | Controversial takes, quotes |
| Product Focus | Clean product shot + benefit text | Reviews, unboxings |

## Common Patterns

1. **The Hook Slide** — First image/text must stop the scroll; bold, unexpected, curiosity-inducing
2. **The Carousel Journey** — Each slide builds on the last; slide 1 hooks, middle delivers, last converts
3. **The Numbered List** — "[X] Ways to..." format works across all platforms
4. **The Before/After** — Transformation content consistently outperforms
5. **The Quote Overlay** — Text on image with strong typography and attribution
6. **The Data Point** — One surprising statistic, large and bold
7. **The Template System** — Consistent layout that becomes recognizable in the feed

## Pitfalls to Avoid

- **Text too small** — Must be readable at mobile thumbnail size
- **Too much text** — Social media images should have 5-10 words maximum
- **Ignoring safe zones** — Profile photos, UI elements, and captions cover parts of your image
- **Wrong dimensions** — Each platform has specific sizes; one size does NOT fit all
- **No branding** — Every image should have at least a logo handle or color
- **Ignoring the algorithm** — High contrast, faces, and bold text perform better algorithmically
- **Desktop-first thinking** — 80%+ of social media is consumed on mobile
- **Static thinking** — Carousel and interactive content outperforms single images
- **Not testing variations** — Always create 2-3 versions for A/B testing
- **Forgetting accessibility** — Alt text, sufficient contrast, readable fonts
- **Platform-naive design** — What works on LinkedIn won't work on TikTok
