# Brand Identity System

> Category: 品牌设计 (Brand Design) | Style: Cohesive Visual Systems | Last updated: 2026

## When to Use

Create complete brand identity systems that extend far beyond a logo. Perfect for:

- New businesses establishing their visual presence
- Rebranding projects needing a fresh visual system
- Product launches requiring consistent multi-platform design
- Startups preparing for investor presentations
- Personal brands scaling to professional presence
- Event series requiring cohesive visual language
- Design system foundations for digital products

## Design Philosophy

A brand identity is a living system — a visual language that communicates consistently across every touchpoint:

- **System over individual** — Each element works alone but shines in combination
- **Consistency builds recognition** — Repetition of visual elements creates memory
- **Personality through design** — Every choice (color, type, pattern) expresses character
- **Flexibility within rules** — A good system allows variation without losing coherence
- **Scalable complexity** — Works for a business card AND a trade show booth
- **Emotional architecture** — The system makes people *feel* something specific

## Decision Priority

1. **Define brand personality** — Who is the brand as a person?
2. **Create color palette** — Primary, secondary, accent, neutral system
3. **Select type system** — Headline, body, accent fonts with hierarchy
4. **Design applications** — How the system works across touchpoints
5. **Document the system** — Guidelines that enable consistent use

## Instructions for AI Assistant

### Step 1: Brand Discovery
Gather or infer:
- Brand name, tagline, mission statement
- Target audience and their aesthetic preferences
- Brand personality adjectives (3-5)
- Competitive landscape
- Aspirational brands (what do they admire?)

### Step 2: Build the Foundation
Create in order:
1. Color palette (primary → secondary → accent → neutral)
2. Typography system (display → body → accent)
3. Logo treatment and clear space
4. Photography/illustration style
5. Pattern and texture elements

### Step 3: Construct the System Prompt
```
Base: "Complete brand identity system for [BRAND NAME], [INDUSTRY],
personality: [ADJECTIVES], audience: [TARGET], style: [DIRECTION],
foundation: color palette [COLORS], typography [FONTS], applications:
[LIST OF TOUCHPOINTS], mood: [EMOTIONAL QUALITY]"
```

### Step 4: Generate Applications
Apply the system to specific touchpoints.

## Prompt Templates

### Minimalist Identity

```
Create a minimalist brand identity system for "[BRAND NAME]", a [INDUSTRY]
brand. Personality: refined, confident, essential. Design language:
- Color: Monochrome foundation ([#000000] black, [#FFFFFF] white, [#F5F5F5]
  light gray) with single accent color [ACCENT COLOR] used sparingly
- Typography: [FAMILY: Inter / Helvetica Neue / Söhne] in [2-3 weights only],
  generous letter-spacing for headlines, tight for body
- Logo: Ultra-minimal [wordmark / geometric mark], no decorative elements
- Photography: High-key, minimal props, generous negative space
- Layout: Asymmetric grid, 60%+ white space, left-aligned text
- Patterns: None — the brand lives in restraint
- Texture: Smooth, no grain, clean digital
Applications to generate: business card, letterhead, website hero, social media
profile, packaging, presentation template.
```

Neutral 3:  #757575 (Gray)     — Secondary text, captions
Accent:     #[BRAND COLOR]     — CTAs, highlights, sparingly (≤10% of any layout)

## Style Reference

### Brand Personality Spectrum

```
PLAYFUL ←──────────────────────────────→ SERIOUS
  │                                        │
  Rounded fonts                           Serif fonts
  Bright colors                           Dark colors
  Hand-drawn                              Geometric
  Irregular grid                          Strict grid
  Lots of illustration                    Photography only

MINIMAL ←──────────────────────────────→ MAXIMAL
  │                                        │
  Fewer elements                          Rich details
  Monochrome                              Full color
  Sans-serif                              Decorative
  White space                             Dense layout
  Flat                                    Textured
```

### Application Specifications

| Application | Size/Format | Key Considerations |
|------------|-------------|-------------------|
| Business Card | 3.5×2 in / 85×55mm | Paper stock, finish (matte/gloss/linen) |
| Letterhead | A4 / US Letter | Margins, header/footer, print vs. digital |
| Envelope | DL / #10 | Return address placement, flap design |
| Email Signature | 600px wide max | Web-safe fonts, image alt text |
| Social Avatar | 400×400px min | Centered, works at circular crop |
| Social Cover | 1500×500px (Twitter) | Safe zone for different crop ratios |
| Website Favicon | 16×16, 32×32, 180×180 | Simple enough for smallest size |
| App Icon | 1024×1024 | No rounded corners (OS adds them) |
| Presentation | 16:9 | Title slide, content, section, closing |
| Packaging | Variable | Print specs: CMYK, bleed, dieline |

### Mood Board Creation Guide

A brand mood board should include:
1. **3-5 aspirational images** — What the brand "feels like"
2. **Color swatches** — 5-7 colors with hex/CMYK values
3. **Typography samples** — Headline, body, accent fonts
4. **Texture references** — Paper, material, surface qualities
5. **Photography direction** — Style, lighting, composition
6. **Competitor analysis** — What exists, what to differentiate from
7. **Anti-references** — What the brand is NOT (2-3 examples)

## Common Patterns

1. **Primary + Tint system** — One main color with 3-4 lighter/darker tints
2. **The 60-30-10 rule** — Dominant color (60%), secondary (30%), accent (10%)
3. **Type hierarchy trio** — Display font + Body font + Accent/mono font
4. **Photography style guide** — Consistent lighting, color grading, composition
5. **Icon system** — Consistent stroke weight, size, style across all icons
6. **Pattern library** — 2-3 repeat patterns for backgrounds, packaging, merchandise

## Pitfalls to Avoid

- **Too many colors** — 2-3 primary + 2-3 neutral is usually sufficient
- **Font overload** — 2-3 font families maximum; more creates chaos
- **Logo-only thinking** — The logo is 10% of the identity; the system is 90%
- **Inconsistent photography** — Mixed photo styles break the visual system
- **Ignoring dark mode** — Modern identities need both light and dark versions
- **No clear space rules** — Define minimum spacing around the logo
- **Missing usage rules** — Document what NOT to do (stretch, recolor, add effects)
- **Design for one application** — Test across ALL touchpoints before finalizing
- **Trend-chasing** — Build for 5-10 year longevity, not 6-month trend life
- **Forgetting accessibility** — Color contrast ratios, font sizes, alt text
- **No file format specs** — Provide SVG, PNG (1x-4x), PDF, EPS for different uses

## 中文版本

### 使用场景

适用于需要创建完整品牌视觉体系的项目，包括：

- 新企业建立视觉形象
- 品牌重塑（rebranding）项目
- 产品上线前的多平台视觉统一
- 创业公司准备投资人演示材料
- 个人品牌向专业化升级
- 系列活动的统一视觉语言
- 数字产品的 Design System 基础

### 核心步骤

1. **品牌调研** — 收集品牌名称、使命、目标受众、3-5 个性格形容词、竞品分析
2. **构建视觉基础** — 按顺序创建：色彩体系 → 字体体系 → Logo 规范 → 摄影/插画风格 → 图案与纹理
3. **组装 System Prompt** — 将品牌名、行业、性格、受众、色彩、字体等信息拼接为结构化 prompt
4. **生成应用场景** — 将系统逐一应用到名片、信纸、网站、社交媒体、包装、演示文稿等触点

### 模板说明

本文件提供四套风格模板：

| 模板 | 适用场景 | 关键特征 |
|------|---------|---------|
| **Minimalist** | 科技、设计、高端品牌 | 单色系 + 单一强调色，大量留白，2-3 种字重 |
| **Playful** | 面向年轻用户的品牌 | 3-4 色饱和色调，圆润字体，手绘插画 |
| **Luxury** | 时尚、酒店、美容、酒类 | 深色 + 金属色，高对比衬线字体，对称排版 |
| **Eco-Friendly** | 可持续/有机品牌 | 大地色系，有机衬线体，再生纸质感 |

遵循 **60-30-10 配色法则**（主色 60%、辅色 30%、强调色 10%）和 **字体三件套**（展示字体 + 正文字体 + 辅助/等宽字体）。

### 常见陷阱

- **颜色过多** — 2-3 个主色 + 2-3 个中性色即可，过多会显得杂乱
- **字体堆砌** — 最多 2-3 个字体家族，超过则视觉混乱
- **只关注 Logo** — Logo 仅占品牌体系的 10%，系统性才是关键
- **摄影风格不统一** — 混合风格会破坏视觉一致性
- **忽略暗色模式** — 现代品牌需同时定义亮色和暗色方案
- **缺乏 Logo 保护区** — 必须定义 Logo 周围最小净空区域
- **追随时尚趋势** — 品牌系统应有 5-10 年的生命周期
- **忽视无障碍设计** — 注意色彩对比度、字号、Alt 文本
- **缺少文件格式规范** — 应提供 SVG、PNG（1x-4x）、PDF、EPS 等格式
