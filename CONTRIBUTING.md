# Contributing to Awesome Creative Skills

Thank you for your interest in contributing! This project thrives on community creativity.

> 感谢你的参与！这个项目因社区的创造力而蓬勃发展。

## Ways to Contribute

### 1. Add a New Skill 🎨

The most valuable contribution! Create a new creative skill file:

1. Open an [issue](https://github.com/liangzhengtao/awesome-creative-skills/issues/new?template=request_skill.md) describing your skill idea
2. Fork the repository
3. Create your skill file in the appropriate `skills/` category folder
4. Follow the [Skill Template](#skill-template) below
5. Submit a pull request

### 2. Improve Existing Skills ✏️

- Add new prompt templates
- Expand style references
- Fix errors or outdated information
- Add new color palettes or typography recommendations

### 3. Report Issues 🐛

- Broken links
- Incorrect information
- Formatting problems
- Missing translations

### 4. Suggest Categories 📂

Have an idea for a new skill category? Open an issue!

## Skill Template

Every skill file must follow this structure:

```markdown
# [Skill Name]

> Category: [category] | Style: [art style] | Last updated: [year]

## When to Use
[When this skill is useful — 2-4 paragraphs]

## Design Philosophy
[Core principles and aesthetic decisions]

## Decision Priority
[Ordered list of priorities when creating]

## Instructions for AI Assistant
[Detailed step-by-step instructions]

## Prompt Templates
[Ready-to-use prompt templates with variables in [BRACKETS]]

## Style Reference
[Color palettes, typography, composition guidelines]

## Common Patterns
[Frequently used patterns]

## Pitfalls to Avoid
[Common mistakes]
```

### Requirements

- **Minimum 150 lines** per skill file
- **Detailed prompt templates** — not just descriptions, but actual prompts with customizable variables
- **Color palettes** with hex codes
- **Typography recommendations** with font names
- **At least 3 prompt variations** per skill
- **Bilingual** — Descriptions in Chinese, prompts and technical terms in English

---

## File Naming

- Use lowercase with hyphens: `my-skill-name.md`
- Place in the appropriate category folder under `skills/`
- Create new category folders if needed (use Chinese name + English description in README)

---

## Pull Request Process

1. Fork the repo and create your branch from `main`
2. Add or modify files following the conventions above
3. Update the README.md skills table if adding a new skill
4. Ensure your skill file has at least 150 lines
5. Submit your PR with a clear description

### PR Title Format

- New skill: `feat: add [skill-name] skill`
- Improvement: `improve: [skill-name] — [what changed]`
- Fix: `fix: [description]`
- Docs: `docs: [description]`

## 贡献指南（中文）

### 如何贡献

1. **添加新技能**：最有价值的贡献！创建新的创意技能文件
2. **改进现有技能**：添加新的提示词模板、扩展风格参考
3. **报告问题**：修复链接、错误信息、格式问题
4. **建议分类**：对新技能分类有想法？请提交Issue！

### 技能文件要求

- 每个技能文件**至少150行**
- 提供**详细的提示词模板**，带有可自定义变量
- 提供**颜色代码**的调色板
- 提供**字体名称**的排版建议
- 每个技能**至少3个提示词变体**
- **中英双语** — 描述使用中文，提示词和技术术语使用英文

感谢你的贡献！🎨
